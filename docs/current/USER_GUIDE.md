# دليل الاستخدام الحالي

مرجع الإصدار 2.6.14 بتاريخ 2026-10-04. [الفهرس](../../README.md).

## الحسابات والاشتراك

مالك المنصة ينشئ شركة المشترك ويدير الاشتراك. مالك الشركة يدير فروع شركته وموظفيه ضمن الاشتراك. الموظف يدخل بكود الشركة واسم المستخدم/البريد وكلمة المرور؛ تطابق كود الشركة لا يمنحه صلاحيات المالك. [دعم واشتراكات وتجديد عبر واتساب](https://wa.me/966564982852).

ابدأ الدخول الجديد أثناء الاتصال. استمرار جلسة محلية لا يعني دعم أول دخول دون إنترنت، أو دخول محاسب آخر بتصريح 24 ساعة؛ هذا المسار والورديات غير مفعّلين.

## الفروع والموظفون

1. أنشئ الفرع وبياناته من حساب مخوّل.
2. أنشئ الموظف وحدد دوره وفروعه، بدل مشاركة حساب المالك.
3. افتح الفرع المختار قبل إنشاء السجلات. التبديل يغير نطاق العرض ولا ينقل أرصدة أو فواتير تلقائيًا.
4. الموظف يرى فروعه المعينة فقط. إن مُنح عرض «كل الفروع»، يجمع فروعه المسموح بها لا فروعًا إضافية.
5. قارِن تقرير الفرع بالفرع نفسه. نقل مخزون فعلي يستخدم تحويلًا موثقًا، لا تغيير الفرع على سجل قديم.

## الشاشات الأساسية

| القسم | الاستخدام |
|---|---|
| الرئيسية | ملخص النشاط والوصول للشاشات المصرّح بها |
| نقطة البيع والميزان | صنف ووزن وعبوة وعميل وخصم وسداد وحفظ/طباعة |
| سجل الفواتير | البحث والعرض والطباعة والتعديلات المسموحة |
| العملاء والديون | بيانات العملاء والتحصيل والأرصدة |
| الأصناف والمخزون | أسعار وكميات وأصناف الفرع |
| المشتريات والموردون | التوريد والسداد وحساب المورد |
| المصروفات والعمال | المصروفات والسلف والرواتب بحسب الصلاحيات |
| المرتجعات والتالف والتحويلات | توثيق حركة لها أثر، بدل تغيير كمية بلا مصدر |
| الشركاء والتقارير | حقوق الشركاء والسحب والتوزيع والنتائج |
| الضبط | المنشأة والخط والطباعة والميزان والمخزون والموظفون والنسخ والمزامنة والأمان والتحديثات |

إظهار القسم يتبع الدور؛ وجود شاشة في المصدر لا يعني إتاحتها للكاشير.

## البيع

اختر صنف الفرع، وأدخل الوزن القائم والعبوات ووزنها الفارغ، وراجع الصافي والسعر والإجمالي. حدد العميل والسداد: نقد، بنك، آجل أو المركب المتاح. راجع الخصم والمطلوب والمدفوع ثم احفظ. فتح نافذة الطباعة ليس وحده دليل حفظ؛ تأكيد الحفظ يأتي بعد التزام التخزين المحلي.

المتسلسل المحلي عرض أولي؛ المرجع النهائي الفريد يحمل UUID كاملة بترميز lossless لمنع تطابق مراجع أجهزة منفصلة. الفواتير القديمة لا يُعاد ترقيمها تلقائيًا.

إذا فشل التخزين أو ظهرت بوابة السلامة، لا تكرر البيع بلا مراجعة ولا تمسح بيانات الموقع. احتفظ بالمصدر واستخدم الاسترداد الموثوق.

## الإعدادات والواجهة

تحسين الألوان والأيقونات والتنقل والهاتف حافظ على المحرك المالي المشترك. عُدّلت الصفحة التسويقية وشعار الفواتير والتقارير والنصوص ورقم الدعم. عولجت إعادة تعيين الحقول قبل الحفظ عند وصول تحديث مزامنة؛ الكتابة ليست حفظًا: اضغط الحفظ وانتظر التأكيد.

اختيارات العملة العربية تشمل الريال السعودي، الدرهم الإماراتي، الدينار البحريني والكويتي، الريال العماني والقطري، الجنيه المصري، الدينار الليبي والأردني والعراقي والتونسي والجزائري، الدرهم المغربي، الجنيه السوداني، الليرة السورية واللبنانية، الريال اليمني، الشلن الصومالي، الفرنك الجيبوتي والقمري، الأوقية الموريتانية والشيكل المتداول في فلسطين؛ بالإضافة للدولار الأمريكي واليورو. هذه تسمية العملة وليست تحويل سعر صرف أو محاسبة متعددة العملات معتمدة.

## المزامنة وقرار المالك

«0 تغييرات بانتظار المزامنة» يعني أن طابور هذا النطاق المحلي فارغ. لا يثبت وصول جميع تغييرات الأجهزة أو غياب التعارضات والبيانات المحجوبة. راجع الاتصال وآخر مزامنة والأخطاء، واستخدم التحديث اليدوي عند الحاجة.

عند تعارض تعديلين غير قابلين للجمع، يحفظ النظام المصدرين. المالك الحقيقي يفتح المراجعة في النسخ/المزامنة، ويقرأ المحلي والخادم ثم يختار ويؤكد. إذا تغيرت رؤوس الخادم، يجب قراءة لقطة حديثة؛ لا تُنفذ التسوية على لقطة قديمة.

الجهاز المتأثر يسترد النتيجة بعد القرار، ويؤرشف أصله قبل تطبيق checkpoint. قرار واحد لا يُسقط تعديلات أخرى معلقة لم تُراجع. إذا رفضت التسوية تاريخًا غير مدعوم تبقى الأدلة محفوظة.

## التحديث والمشاكل الشائعة

- نزّل من الإصدار الرسمي أو داخل البرنامج فقط، وتحقق من الإصدار بعد إعادة الفتح.
- تحذير ناشر Windows ممكن لأن المثبّت غير موقّع بـ Authenticode ؛ لا يُتجاوز تحذير بالنيابة عن المستخدم.
- بعد تغيير كلمة المرور، أعد الدخول متصلًا بالكلمة الجديدة؛ تُلغى الجلسات القديمة. التغيير الطبيعي لا يحتاج المطوّر كل مرة.
- صنف غائب: افحص الشركة والفرع والصلاحيات والمزامنة؛ لا تمنح صلاحيات إضافية أو تمسح Cache قبل حفظ المصدر.
- شاشة حماية: احتفظ بالبيانات واتبع الاسترداد/الأرشفة. وجود أرشيف لا يعني دمجه في الدفتر.
- 401 جلسة، 403 صلاحية، 409 تعارض، 503 تعذر خدمة. تكرار الضغط ليس علاجًا عامًا.
