## (One Product — Multiple Platforms Architecture)

---

### 1. الرؤية العامة والهدف الأساسي
تم توحيد المنظومة المحاسبية ونقاط البيع لتكون **منتجاً برمجياً واحداً متكاملاً** يعمل عبر 3 منصات رئيسية:
1. **الويب السحابي (Cloud Web Application)**: يعمل عبر المتصفح السحابي ومستضاف على حافة شبكة Cloudflare العالمية (Cloudflare Pages + D1 Database + Workers Edge Functions).
2. **برنامج سطح المكتب (Windows Desktop Application)**: يعمل كبرنامج تنفيذي مستقل مبني بإطار عمل **Electron 40** ومدمج بنوافذ بدون إطار (Frameless window controls) مع إمكانية العمل بقاعدة بيانات محلية SQLite وسحابية D1.
3. **تطبيق الهاتف الذكي (Android & iOS Mobile Application)**: تطبيق جوال حقيقي مدمج بإطار عمل **Capacitor 7** يدعم اللمس السريع، شاشات البيع والباركود، وطابعات البلوتوث والإيصالات الحرارية.

---

### 2. مصفوفة المنظومة الموحدة (Unified Matrix)

| العنصر البرمجي | منصة الويب (Web) | سطح المكتب (Desktop) | تطبيق الجوال (Mobile) |
| :--- | :--- | :--- | :--- |
| **محرك الواجهات (UI/UX)** | React 18 + Tailwind CSS + Framer Motion | React 18 + Framer Motion | React 18 (Mobile Hub + Touch UX) |
| **المحرك المحاسبي والرياضي** | `useAppStore` (Single Source of Truth) | `useAppStore` (نفس المحرك 100%) | `useAppStore` (نفس المحرك 100%) |
| **قواعد البيانات والتخزين** | Cloudflare D1 + LocalStorage Cache | SQLite Local + Cloudflare D1 Cloud | LocalStorage + SQLite/Capacitor Sync |
| **الطباعة** | طباعة المتصفح القياسية A4 وإيصال | طباعة مباشرة حرارية عبر بروتوكولات النظام | طباعة بلوتوث وشبكية ESC/POS |
| **نظام الإصدارات** | فحص تلقائي + Service Worker Cache | فحص تلقائي عبر SemVer API | فحص تلقائي عبر SemVer API |

### 3. طبقة إدارة الإصدارات والتحديثات الموحدة (Central Release Engine)

#### أ. عقد البيانات والواجهات (`src/types/contracts.js`):
```javascript
export const PLATFORMS = {
  WEB: 'web',
  WINDOWS: 'windows',
  ANDROID: 'android',
  IOS: 'ios'
};

export const UPDATE_TYPES = {
  OPTIONAL: 'optional',       // إشعار غير ملزم
  RECOMMENDED: 'recommended', // موصى به مع إمكانية التأجيل
  REQUIRED: 'required'        // إجباري: إغلاق التطبيق حتى التحديث
};
```

#### ب. خوارزمية فحص ومقارنة الإصدارات (`src/config/appVersion.js`):
- تعتمد المقارنة القياسية Semantic Versioning (`major.minor.patch`).
- إذا كان رقم إصدار العميل أدنى من `minimum_version`، يتم رفع مستوى التحديث إلى **`required`** تلقائياً، لحماية بيانات المشترك من التناقض أو التلف.

#### ج. قاعدة بيانات الإصدارات على Cloudflare D1:
- جدول `app_releases` يدير كافة سجلات الإصدارات وتفاصيلها وروابط التحميل وحالتها (`published`, `deprecated`).
- واجهة API حافة الشبكة (`functions/api/releases/latest.js` و `functions/api/releases/index.js`) تقدم بيانات التحديثات بسرعة استجابة تقل عن 50ms عالمياً.

### 4. بوابة الدخول وتحميل التطبيقات الموحدة (`LoginView.jsx`)
توفر صفحة الدخول الموحدة للمشتركين والعملاء:
1. نموذج تسجيل الدخول السحابي السريع.
2. تبويب "تحميل التطبيقات" للوصول المباشر إلى:
   - رابط برنامج سطح المكتب لويندوز: `KhodarPOS-Setup.exe` (v2.4.0, ~115 MB).
   - رابط تطبيق الأندرويد المباشر: `KhodarPOS.apk` (v2.4.0, ~3.4 MB).
   - زر تثبيت تطبيق الويب التقدمي (PWA) لأجهزة آبل iOS وأندرويد.

---

### 5. مركز التحديثات التفاعلي داخل التطبيق (`UpdateNotificationModal.jsx`)
- يظهر للمستخدم إشعار فوري عند توفر إصدار أحدث للمنصة التي يعمل عليها.
- يعرض مقارنة واضحة: `الإصدار الحالي v2.2.0 ➔ الإصدار الجديد v2.4.0`.
- يعرض قائمة تفصيلية بالتحسينات والميزات الجديدة.
- في التحديثات الإجبارية (`required`)، يتم تعطيل زر "لاحقاً" وإلزام المستخدم بالتحديث لضمان سلامة العمليات المحاسبية.

---

### 6. لوحة إدارة الإصدارات المركزية (Super Admin Release Portal)
- تتيح لمالك النظام ومشرفي السحابة:
  1. مراقبة حالة المنصات الأربع (Windows, Android, Web, iOS).
  2. نشر تحديثات جديدة وإصدارات SemVer وتحديد مستوى الإلزامية وروابط التنزيل.
  3. حفظ وتطبيق التحديثات فورياً ومزامنتها على Cloudflare D1.

---

### 7. التزام صارم بالمعايير المحاسبية (Accounting Integrity)
- **لا وجود لبيانات وهمية (Zero Mock Data)**.
- تم التحقق من جميع المعادلات المحاسبية:
  - احتساب توريدات العملاء النقدية في الدرج.
  - خصم المشتريات النقدية بدقة.
  - سداد الموردين يخصم مرة واحدة فقط من الدرج أو البنك.
  - سداد رواتب العمال يخصم مباشرة من الكاش.
  - توزيع الأرباح يخصم من الحساب البنكي.
  - حساب العجز الواقعي دون تصفير قسري.
