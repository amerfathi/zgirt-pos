Financial operations retain immediate durable local save and outbound delivery. Empty four-second polling is replaced with activity refresh (coalesced for five minutes) and a randomized one-to-two-hour recovery fallback. Authenticated online financial actions refresh server changes before local commit. Offline work stays pending; the existing D1 causal checks reject stale concurrent pushes without deleting the outbox.

Inbound synchronization drains paginated history. Pending writes retry with backoff; authorization and causal conflicts are surfaced rather than retried endlessly. The connection badge now distinguishes connectivity from the last successful inbound check. The production-release workflow requires lint, core typecheck and the full test suite before building either platform.
