## Windows updater

- After the verified installer is downloaded, the application schedules a detached handoff, closes normally, and opens the installer only after the application process exits.
- If the application does not exit within 180 seconds, or the verified installer is missing or cannot start, the handoff shows an error instead of silently claiming installation succeeded.
- The update screen now describes the automatic close and install sequence.

## Verification

- The 2.6.11 installer reproduced the running-application warning while BRAKA remained open. Closing BRAKA and retrying completed the installation, confirming the process race.
- Six focused updater tests, lint, typecheck, security regression, 184 integration tests, and the accounting/QA suites passed locally.
- A 2.6.11-to-2.6.12 update starts under 2.6.11's old updater. The automatic handoff behavior itself requires a subsequent update started from 2.6.12 or a staging equivalent to verify end to end.
