## 1. أجنحة الاختبار المجدولة (Execution Suites)

### Suite 1: Real Browser Full User Journey (E2E)
- **المسار الكامل**: الموقع التسويقي ➔ طلب التجربة ➔ تسجيل الدخول ➔ شاشة الكاشير ➔ إضافة عميل ➔ وزن صنف ➔ خصم ➔ إصدار فاتورة نقدية ➔ إصدار فاتورة آجلة ➔ استعراض السجل ➔ مرتجع مبيعات ➔ تسجيل مشتريات ➔ تسجيل مصروفات ➔ فحص كشف الحسابات ➔ التقارير ➔ التحديثات ➔ تسجيل الخروج.
- **الأدوات**: Puppeteer مع Chrome الحقيقي.

### Suite 2: POS Breaker & Concurrency Test
- **النقر السريع (Rapid Clicking)**: الضغط 10 مرات متتالية خلال 100ms على زر "حفظ وطباعة الفاتورة" للتحقق من عدم إنشاء فواتير مكررة أو تكرار خصم المخزون.
- **التفريغ والتعديل المفاجئ**: تعديل السعر أو الوزن أثناء معالجة الفاتورة.
- **فحص منع المخزون السالب**: محاولة بيع كمية تتجاوز الرصيد المتوفر عند تفعيل المنع.

### Suite 3: Complete Accounting Invariants & Ledger Audit
- **الدورة المالية المتكاملة**:
  1. رصيد افتتاحي للخزينة: $10,000$ ج.م
  2. فاتورة مشتريات بضاعة آجلة من مورد: $5,000$ ج.م
  3. سداد جزء من حساب المورد نقداً: $2,000$ ج.م (رصيد الصندوق: $8,000$ ج.م، التزام المورد: $3,000$ ج.م)
  4. بيع نقدي: $3,000$ ج.م (تكلفة البضاعة المباعة COGS: $2,000$ ج.م)
  5. بيع آجل لعميل: $1,500$ ج.م (مدفوع: $500$ ج.م، دين العميل: $1,000$ ج.م)
  6. سداد العميل لجزء من الدين: $400$ ج.م (دين العميل المتبقي: $600$ ج.م)
  7. تسجيل مصروف تشغيلي (كهرباء): $300$ ج.م
  8. مرتجع مبيعات نقدي من العميل: $200$ ج.م
- **المعادلات المحاسبية المطلوب إثباتها رياضياً وبرمجياً**:
  - `Cash In Treasury = Initial + SalesCash + CustomerPayments - SupplierPayments - Expenses - SalesReturns`
  - `Customer Receivables = CreditSales - CustomerPayments - SalesReturnsOnCredit`
  - `Supplier Payables = CreditPurchases - SupplierPayments`
  - `Gross Profit = Sales - COGS - SalesReturnsCost`
  - `Net Profit = Gross Profit - Operating Expenses`
  - `Total Debit == Total Credit (Zero Variance)`

### Suite 4: Multi-Tenant Security & Role Escape
- محاكاة متجرين `TENANT_A` و `TENANT_B`.
- محاولة الوصول لبيانات المتجر `B` من خلال المتجر `A` عبر الـ API ومطالعة الفواتير.
- محاكاة مستخدم برتبة كاشير ومحاولة فتح مسارات التقارير والإعدادات والمستخدمين.

### Suite 5: Electron Desktop Security & File Integrity
- فحص ملفات Electron (`main.cjs`, `preload.cjs`).
- التحقق من حظر الملاحة الخارجية غير المصرح بها.
- فحص أمان IPC والمثبت التنفيذي.

### Suite 6: Mobile Touch & Responsive Stress
- اختبار أبعاد الهواتف الذكية (375x667, 390x844, 412x915).
- فحص شريط الملاحة السفلي وتراكب النوافذ المنبثقة (Modals).
