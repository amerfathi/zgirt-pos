# زقيرت (ZGIRT) — منظومة كاشير ومحاسبة التبغ والسجائر والجملة

المرجع التجاري المعتمد؛ الإصدار الحالي **2.6.14**. منصة متكاملة بواجهة عربية تعمل على الويب و Windows و Android، مع دعم كامل للتشغيل دون اتصال (Offline-First) وحفظ محلي متين ومزامنة سببية سحابية عبر Cloudflare.

---

## 🌟 الهوية والنشاط التجاري

**زقيرت (ZGIRT)** مصممة خصيصاً لتجارة التبغ والسجائر بالتجزئة والجملة:
- **إدارة الهرمية الحجمية للتبغ:** كرتونة $\rightarrow$ باقة/علبة $\rightarrow$ سجارة فردي، مع دعم الباركود المخصص لكل مستوى تعبئة وتجزئة الكراتين آلياً.
- **نظام كاشير فائق السرعة:** بيع قطاعي وجملة، خصومات معتمدة، فواتير معلقة، ومرتجعات موثقة.
- **حسابات تجار الجملة والوكلاء:** دفاتر ديون العملاء والموردين، حدود الائتمان، وسندات القبض والدفع.
- **الخزينة والأدراج النقدية:** دقة متناهية بحساب السنتات دون فواصل تقريب، وجرد مطابق.
- **تطبيقات متعددة المنصات:** تطبيق ويب PWA، تطبيق ويندوز لسطح المكتب مع دعم الطابعات الحرارية، وتطبيق أندرويد متوافق مع قارئات الباركود المحمولة.
